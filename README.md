
# Movie Sentiment Analysis

## Project Overview

This project involved annotating 100 movie reviews using sentiment classification in Label Studio.

The goal was to categorize written movie reviews according to the sentiment expressed in the text, using positive and negative labels.

## Project Objective

To gain practical experience in text classification and data annotation by reviewing movie reviews and assigning appropriate sentiment labels.

## Tools and Technologies

- **Label Studio:** Used for text annotation and sentiment classification.
- **Docker Desktop:** Used to run the Label Studio environment.

## Annotation Process

1. Imported a collection of 100 movie reviews into Label Studio.
2. Read and examined each review to understand the sentiment expressed.
3. Assigned the appropriate sentiment label (Positive or Negative).
4. Completed and recorded the annotations in Label Studio.
